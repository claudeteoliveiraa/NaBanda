# NaBanda

- Ano letivo: 2026-2027
- Semestre: 3º
- Curso: Licenciatura em Engenharia Informática
- Unidades curriculares: Projeto Mobile, Redes e Comunicação de Dados, Bases de Dados, Interfaces e Usabilidade, Matemática Discreta, Programação de Dispositivos Móveis
- Docentes: Fábio da Silva, Pedro Rosa, Miguel Boavida, Paula Neves, André Trocado, João Monge

## Resumo
O NaBanda é uma aplicação móvel que transforma a localização GPS do utilizador numa morada digital, com código único, QR Code e referências fotográficas, pensada para contextos urbanos sem sistema formal de ruas, como em Angola.
